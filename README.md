# 筋トレノート

筋トレの **前・最中・後** をまるごと支えるブラウザアプリ。
インストール不要・アカウント不要で、スマホのホーム画面に追加すればアプリのように使えます。

**▶ https://tmgr490.github.io/kintore/**

記録はすべて端末のブラウザ内（localStorage）に保存され、サーバーには送信されません。

---

## 機能

### 筋トレ前 — 計画とその日の判断
- **週間スケジュール**：曜日ごとにメニューを割り当て、カレンダーで俯瞰
- **分割法テンプレート**：全身3日／上下2分割／PPL週6・週3／ブロスプリット／StrongLifts 5×5／自宅・自重／筋力特化
- **今日のメニュー自動決定**：予定・前回実績・部位の回復状況から組み立て。予定外の日も「いちばん間隔が空いているメニュー」を提案
- **コンディションチェックイン**：睡眠・疲労・ストレス・やる気・部位別の筋肉痛から準備度を算出し、重量とセット数を自動で増減（オートレギュレーション）
- **前回実績からの目標提示**：ダブルプログレッションで「次に狙う重量と回数」を種目ごとに提示
- **ウォームアップ自動生成**：メイン重量から逆算し、実際に組める重量に丸めて提示
- **器具プロファイル**：ジム／自宅ごとにバー重量・所持プレート・ダンベルの刻みを登録。提案重量は必ず「実際に作れる重量」になる
- **痛み・故障の登録**：該当部位を使う種目に注意マークを出し、代替種目を提案

### 筋トレ中 — 実行と記録
- **高速セットロギング**：重量・回数・RIR を大きなタップ領域で入力、前回値ワンタップコピー
- **セット種別**：ウォームアップ／本番／ドロップ／AMRAP／失敗、スーパーセット
- **レストタイマー**：セット完了で自動起動。終了時刻ベースなので画面を閉じても正確。音と振動、±15秒
- **プレート計算機**：片側に積むプレートを図で表示（器具プロファイル連動）
- **次セット案内**：休憩中に「次は◯kg × ◯回」を表示
- **自己ベストのリアルタイム検知**：推定1RM・最高重量・最高回数の更新をその場で通知
- **部位別セット数の進捗**：今日どこをどれだけ鍛えたか
- **種目のワンタップ差し替え**／セッションの中断・再開

### 筋トレ後 — 振り返りと次への反映
- **セッションまとめ**：総ボリューム・所要時間・部位別セット数・自己ベスト・前回比
- **セッションRPEのフィードバック**：次回の重量とセット数の調整に反映
- **進捗グラフ**：推定1RMの推移（種目別）、週間ボリューム、部位別セット数、体重・体脂肪率
- **実施カレンダーとヒートマップ**、連続週
- **部位の回復ゲージ**：最終刺激からの経過とボリュームから回復度を推定し、次に鍛えるべき部位を提示
- **停滞検知とデロード提案**：伸び率・RIR・MRV超過から判定し、やり方まで提示
- **筋肉バランス分析**：押す／引く、上半身／下半身、前面／背面の比率と助言
- **体組成記録**：体重・体脂肪率・各部位のサイズ
- **クールダウン提案**：その日鍛えた部位に応じたストレッチ
- **JSONバックアップ**の書き出し／読み込み

### 基盤
- 種目ライブラリ 170種目（日本語・部位／器具／動作パターン／代替種目つき、自作種目の追加も可）
- PWA（ホーム画面に追加・オフライン動作）
- ダーク／ライト自動切り替え、kg／lb 切り替え
- トレーニング理論ガイド（%1RM早見表、RIR/RPE、MEV/MAV/MRV、1RM計算機）

## 構成

ビルド不要の静的サイト。ネイティブ ES Modules のみで、外部ライブラリも CDN も使っていません。

```
index.html               アプリシェル（下部5タブ）
manifest.webmanifest     PWA マニフェスト
sw.js                    Service Worker（network-first）
css/app.css              デザイントークンとレイアウト
js/
  app.js                 起動・タブ切り替え・再描画
  store.js               localStorage 永続化・スキーマ移行・旧アプリからの取り込み
  data/                  部位マスタ・種目ライブラリ・プログラム・理論データ
  engine/                1RM / プレート / ウォームアップ / 進捗提案 / 体調調整 /
                         ボリューム / プランナー / 分析
  ui/                    画面（home, session, plan, stats, settings ほか）
```

### 開発

```bash
python3 -m http.server 8000     # そのまま開けば動きます
```

`main` に push すると GitHub Pages が更新されます。Service Worker は
network-first（かつ `cache: 'no-store'`）なので、**リロードすれば必ず最新のコードが読み込まれます**。
キャッシュはオフライン時の保険としてのみ使われます。
